# Getting Started with AITraining

AITraining is a hands-on curriculum for developers learning to work effectively with AI coding assistants. You'll learn how to set up your environment, communicate intent clearly, and build production-quality software faster.

!!! tip
    Complete the **Setup** section before starting the AI-Assisted Development modules — the exercises depend on a working local environment.

## Welcome

AI coding assistants are most powerful when you know how to guide them. This training covers the full workflow: from configuring your IDE and repository to writing precise instructions, generating tests, and reviewing AI-produced code critically.

Each module has a checklist so you can track what you've covered. Work through them in order or jump to what's most relevant to your role.

## Prerequisites

- Basic familiarity with a terminal and git
- Python 3.10+ or Node 18+ installed
- Access to an AI coding assistant (Claude Code, Cursor, GitHub Copilot, etc.)
- A code editor (VS Code, JetBrains IDE, or Neovim)

## Quick Start

If you're in a hurry, here's the minimum to get productive:

```bash
# 1. Clone the training repo
git clone https://github.com/your-org/altraining
cd altraining

# 2. Install dependencies
pip install -r requirements.txt   # or: npm install

# 3. Open in your AI-enabled IDE
code .   # VS Code with Copilot / Claude extension
```

Then open the **IDE Setup** guide to configure your assistant correctly.
